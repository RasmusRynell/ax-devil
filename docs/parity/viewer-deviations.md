# Parity deviations: offline playback, inspection and render catalogs

Where the [viewer](viewer.md) rows differ from the reference. The offline decisions taken with the owner are in
[14](../rebuild/14-build-order.md#decisions-taken-for-offline-video).

| Row | Deviation | Reason |
|-----|-----------|--------|
| OF-02 | Lanes share one video; the reference let a secondary lane have its own video, length and frame rate, aligned to the primary's frame index | D19: two recordings side by side are two viewers |
| OF-02 | The playlist's entry controls (previous, next, entry list) are in a header above the video; the reference put them in the transport bar. [human] the owner chose to fix only the lane gutters and the inspection lag, and to leave this | Owner decision |
| RC-01 | Catalog schema v4 replaces v3: rules plus ordered layers, label placement lists, one expression language, no `extends` and no `id` (a user catalog is its file). The reference's catalogs do not load. A label without a background is sized by its ink alone, not by font metrics when a filled label shares its batch `[AI]` | D25: the frontend evaluates catalogs per lane; D33: location is identity |
| OF-04 | Sync and sticky tolerance is a numeric setting of each lane; the reference fixed it at 50 ms | D34: tolerance is part of the Lane Policy |
| OF-06 | The frame cache lives in `playback`, not `media` | Eviction follows playback windows; export, thumbnails and live skip it |
| OF-06 | Eviction takes the frame farthest from the playhead outside the protected windows; the reference used LRU | It suits scrubbing: after a jump, frames around the old position are the least wanted |
| OF-06 | Auto is never below 256 MiB; the reference had no floor | The setting's smallest value; a low-memory machine still gets a cache |
| OF-01 | The index is built by scanning packets; the reference decoded the whole video. The decode scan is the fallback | Spike: 1.1 s against 36 s for 10 minutes of 1080p30, same results |
| OF-01 | The index is valid by a stat fingerprint plus a digest of the first and last 64 KiB; the reference used the stat fingerprint alone | Hashing a huge video defeats instant reopen |
| OF-01 | Walking back through a group longer than the budget decodes a block of half the budget at a time | No keyframe group is decoded twice to keep one more frame |
| OF-01 | The client ends the session when the protocol version in `Opened` differs from its own | A stale window stops with a message, not misparsed frames |
| OF-01 | Playback commands sit in a View > Playback submenu; the keys, including Left and Right for 10 frames, are the reference's | There is no Playback menu |
| IN-03 | Hover and click pick over the lane's filtered rows, not what was drawn, so an object that draws nothing can still be hovered and selected; the reference picked from the drawing | D36: picking is frontend only, with no drawing pass to ask |
| IN-01 | Only the Events tab shows a count; an object with no events has no Events section, where the reference showed an empty one | Terse layout: the Objects count is the list's own `N of M` |
| RC-03 | Copy is an inline Name field in the lane menu's Look page, not a dialog | The lane menu is where a catalog is chosen |
| RC-03 | A copy records `origin` as a plain string with no base hash, so there is no "modified" note | A copy is the source text under a new name |
| RC-03 | Copy refuses a source with a duplicate top-level key; the file name is lowercased, not casefolded | The compiler would silently keep the last key |
| RC-03 | A file name that cannot be an id is listed invalid and cannot be deleted; at most 256 files are listed | A catalog id is the file name as text; the folder poll is bounded |
| RC-04 | `catalog render` is dropped; `check` still exercises the catalog on the Overview example item without drawing a picture | Owner decision: "remove all of it with the preview render catalog stuff", after RC-03 dropped the preview sheets |
| RC-04 | [AI] Step 2: `catalog use` saves through the local backend on `$PORT` (7330 by default), or writes the settings file after connection refusal. Discovery is a point-in-time probe: a backend can start after refusal or stop before PATCH. Python notices its separate default file asynchronously through its folder watcher | Reuse the shell’s discovery and existing Owner PATCH to preserve one writer; no settings-file watcher or separate default file |
| RC-02, CAT-A004 | No `Other views use: …` summary line in the lane menu and no `Apply to all N` count on the button. [human] skip | Owner decision; the lane menu's Apply to all lanes still does the work |
| RC-02 | The default catalog is a Personal setting, so it does not follow `storage.catalog_dir` | A Personal setting travels with the person, not with a folder |
| VPC-016, VPC-017, VPC-A003, DRW-A001 | The side panel has no hover grip, double-click toggle or 400 ms width animation: only its command, Close button and divider open, close and resize it. The width follows the reference's rule and the video shrinks beside it | Owner decision: buttons and the divider are discoverable, a grip is a hidden hover target |
| VPC-009 | Wheel zoom scales with the wheel delta, at most one 1.15x step per event; the reference zoomed a full step per event by its sign, so a trackpad jumped to the limit and a horizontal scroll zoomed out. A mouse notch is identical | A trackpad sends many small deltas |
| VPC-010 | Panning starts after 3 CSS px; the reference panned from the first pixel, so a zoomed click with any movement did not select. A double click resets the view (new; the reference reset only through the menu or Ctrl+0) | A click that wobbles still selects |
| DRW-004 | Catalog v4 has no open polyline mark; the reference had one | No built-in catalog or decoder used it |
| DRW-006 | Overlay text is laid out per glyph, without pair kerning or ligatures (joining scripts rasterize whole lines); the reference shaped it through Qt. Class names differ by about 0 to 1 px, digits not at all | The canvas lays text out itself |
| VPC-019 | [AI] Hide in a lane's menu keeps the playhead; the reference restarted the video from zero | The restart lost the user's place for a change that only skips a lane |
| OF-01, OVV-003 | [AI] An overlay that fails to load fails its lane alone (its chip says why) and the video and other lanes play; the reference failed the whole entry. A video or overlay file that is missing or unreadable, an unknown decoder or bad options still fail the whole item | Overlays load per lane after the video opens, and a failed lane never holds a frame back |
| OF-07 | [AI] The next entry is prepared by a thread of the backend, not a child process. The viewer names the entry it steps to and the lanes it shows, so hidden entries and lanes are skipped as stepping skips them; one preparation runs for the whole backend and a new one replaces it | The child process only escaped Python's interpreter lock; the entry is looked up in the viewer's own Content, so a viewer can have only that Content's files read |
| IN-07 | [AI] The object filter that Make default saves also holds the lane's expression, which the reference had no counterpart for; an expression that no longer compiles when a lane starts is dropped, with the ranges, and the class switches stay. `Filter N` in the lane menu counts class switches and bounded ranges as the reference's button did, plus a non-empty expression. `Apply to all` copies to the viewer's other lanes (D34), not to every open viewer | The expression is new; a default must not make a lane run an expression it cannot compile |
| LVV-A002 | [AI] Fix KD-10: reliable Objects/Events help, including empty lists (step 2) | Python defines the help in `media_tools_section.py` but fails to expose it on the tabs; missing help contradicts the spec. Native titles and accessible descriptions retain it regardless of count. |
| SCN-005 | [AI] JSON coordinate arrays allow finite outside values | An explicit wire contract, rather than Python constructors |
| SCN-005 | [AI] Keep rejecting inverted boxes and nonfinite points, including outside points (step 2) | Python's missing box validation produces negative dimensions/area, invalid for layout and smallest-area picking; its outside bypass also admits NaN/infinity, which cannot represent image positions. Flat boxes remain accepted. |
| RC-04 | [AI] The default catalog is a built-in catalog or a file in the catalog folder; `catalog use PATH` refuses a file elsewhere, and `catalog new --from FILE` copies it into the folder first. The reference saved any file's path | Catalogs are served to every viewer by id from the library, so a path outside it would be read and sent past the library's checks |
| OFS-001 | [AI] A file's video is its first video stream that is not cover art (an attached picture); the reference took the first video stream | Cover art is not a video track, and listed first it would make a music file's picture the video |
| OFS-004 | [AI] A video with a frame that has no timestamp is refused with "A frame of the video has no timestamp"; the reference skipped such frames | A frame without a timestamp has no identity, so refusing keeps the index and the file's frame count honest; the reference skipped such frames in the index yet still counted them when reading in order. The spec leaves it undecided |
| SCN-004 | [AI] Keep same-clock, forward TimeSlices and absent spans as None (step 2) | Same-clock forward intervals describe elapsed time; mixed endpoints have no comparable duration and reversed endpoints do not describe elapsed time. An absent entity span is None rather than Python's datetime sentinels. |
| OF-01, OVV-007, VPC-006 | [AI] Native timeline keyboard changes seek immediately; Python changed only the readout until pointer release | Step 2: retain the rewrite's keyboard seeking so the readout and picture agree; the spec flags the Python seek-hook gap for a decision |
| OFS-004 | [AI] Duplicate PTS retain ordinal identity on reads and seeks; ambiguous seek anchors are skipped | Step 2: Python retains duplicates but its reverse map can select the wrong image; ordinal matching and an earlier unambiguous anchor preserve the requested image |
| IN-01, SCN-014 | [AI] Step 2: bounded field pages (4096 fields, 8 MiB of paths/text), at most 64 current pin previews (16 KiB text and 64 KiB path-segment data each, in UTF-8 bytes), at most 8 MiB for a cached classification-order permutation (larger counts are refused), and a 256 MiB ceiling for an explicit value or complete Raw JSON copy; one byte more is refused | Allocation bug fixes, with explicit limits: Python retains the complete field list and has no corresponding copy ceiling. Path tuples share parent strings in `scene/inspection.py`; dotted labels are materialized in `object_inspection/rows.py`. Whole Raw copying and path-based pins are preserved within the bounds |
| IN-01, SCN-014 | [AI] Step 2: unanswered inspection socket reads settle unavailable after bounded retries/response windows; a fresh selection/query, sample, connection or permission restoration may retry | Rewrite-only transport bug fix: Python projects held fields locally, with no corresponding unanswered permission-gated socket request. A denied or dropped reply must not leave Loading forever |
