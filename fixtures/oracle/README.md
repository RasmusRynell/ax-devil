# Oracle fixtures

Output of the reference Python app at commit `e31a7453` (catalog engine and MOT decoder), generated by
`generate.py` in this folder. Rust tests and the frontend's `present/oracle.test.ts` compare against these files ([09](../../docs/rebuild/09-testing.md#oracle-policy));
nothing here is edited by hand. Generated with Python 3.12.14, NumPy 2.5.3, PySide6 6.11.2 (offscreen), from the
reference `uv.lock`.

## Regenerate

```bash
git worktree add --detach /tmp/ax-oracle-wt e31a7453
cd /tmp/ax-oracle-wt && HOME=/tmp/ax-oracle-home XDG_CACHE_HOME=/tmp/ax-oracle-home/c XDG_CONFIG_HOME=/tmp/ax-oracle-home/f \
  XDG_DATA_HOME=/tmp/ax-oracle-home/d uv sync --python 3.12 --frozen --no-dev
# from this repository (private HOME as above, QT_QPA_PLATFORM=offscreen):
/tmp/ax-oracle-wt/.venv/bin/python fixtures/oracle/generate.py --old-tree /tmp/ax-oracle-wt
git worktree remove --force /tmp/ax-oracle-wt
```

The script runs only against that checkout and is deterministic (two runs give identical bytes).

## Scene form (C2)

`{"scene_version":"4.1","scenes":[Scene...]}`, one entity per line.

```
Scene       {"time":{"start":T,"end":T},"entities":[Entity],"events":[],"relations":[{"type","source","target"}],"debug":{}}
T           {"frame":N} | {"us":N}
OT          {"frame":N} | {"us":N} | {"frame":N,"us":N}   an observation has at least one key; N may be negative
Entity      {"id","observations":[Observation],"end_reason":null,"motion_state":null|"moving"|"stationary"|"unknown"}
Observation {"time":OT,"geometry":G,"classifications":[{"type","score":null|f,"confidence":null|f,"attributes":{name:value}}],
             "measurements":{"image_velocity":{"vx","vy"}}}   (measurements, source_data, debug only when present)
G           {"box":[left,top,right,bottom]} | {"polygon":[[x,y],...]}   normalized, may lie outside 0..1
```

Attributes are ordered objects. A colour classification (Python `ColorClassification`) is the map
`{"name","rgb":[r,g,b],"score"}`; `*_colors` attributes are lists of them. Relations are sorted by (type, source, target).
Floats are the old app's `float64` values, not rounded. Box corners are as Python computed them (`x + w` on
normalized values), so a Rust decoder may differ in the last bits: compare with a tolerance.

## Canonical Drawing Instructions (C5)

File: `{"catalog","sheet","variant","target":[1280,720],"hidden":[...],"diagnostics":[{"code","location"}],"instructions":{...}}`.
`instructions` has the keys `boxes circles lines points polygons polylines texts labels`, each a list of rows, one row per
line. Shared paint is resolved into every row; strings are resolved; coordinates are normalized, lengths relative to
min(1280,720). Every float is rounded to 5 decimals (`-0` becomes `0`). A candidate's output must be rounded the same way and
compared with an absolute tolerance of 2e-5 per number (rounding and f32 error), after sorting both sides.

| Kind | Row fields in order (also the sort order) |
|------|-------------------------------------------|
| boxes | `x y w h pen[3] pen_width dashed brush[4] radius` |
| circles | `x y r pen[3] pen_width dashed brush[4]` |
| lines | `x1 y1 x2 y2 pen[3] pen_width dashed` |
| points | `x y pen[3] pen_width` |
| polygons | `points[[x,y]...] pen[3] pen_width dashed brush[4]` |
| polylines | `points[[x,y]...] pen[3] pen_width dashed` |
| texts | `x y text anchor color[3] font_family font_size` (`color` is the paint's pen) |
| labels | `x y anchor size family background(null\|[r,g,b,a]) padding_x padding_y radius gap runs[{text,bar(null\|f),rgb[3],weight}]` |

Rows are sorted by their leaves in field order; each leaf is compared as (rank, value) with rank 0 for null, 1 for numbers
and booleans (false < true), 2 for text (byte order). Labels without a visible run and label backgrounds with alpha 0
(`null`) are normalized as shown; label run `bar` is clamped to 0..1 in hundredths. Row order inside the old output is
not preserved (the draw order is shapes, then text, then labels).

Caveats for the comparison: score text uses Python `f"{v:.2f}"` (0.125 gives `0.12`, 0.375 gives `0.38`), and trimmed
ids use the ellipsis character (`untra…d:0:2`).
